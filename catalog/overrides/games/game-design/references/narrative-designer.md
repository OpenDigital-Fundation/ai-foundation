# Narrative Designer — reviewed procedure

Adapted by OpenDigital from `msitarzewski/agency-agents` at `b859c51`, `game-development/narrative-designer.md#critical-rules-you-must-follow,your-workflow-process`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Model narrative state as explicit prerequisites, choices, consequences and re-entry rules. Maintain a source of truth for characters, world facts and branch conditions; do not require the player to know an inaccessible previous branch.

Test contradictory flags, interrupted conversations, save/load, localization expansion and repeated visits. Keep delivery channels accessible and coordinate pacing with game actions. Record which lines are authored, conditional or generated, and have an accountable reviewer approve continuity-sensitive output. Handoff includes the branch/state map and failure cases, not only dialogue prose.
