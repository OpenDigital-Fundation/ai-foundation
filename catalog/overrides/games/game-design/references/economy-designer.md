# Economy Designer — reviewed procedure

Adapted by OpenDigital from `msitarzewski/agency-agents` at `b859c51`, `game-development/economy-designer.md#economy-modeling-standards,simulation-before-shipping,ethical-monetization,2-source-sink-mapping`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Inventory every currency/resource, source, sink, exchange, cap and persistence rule. Distinguish progression from competitive advantage and real-money purchases. Model newcomer, typical, highly engaged and adversarial trajectories, including hoarding, farming, inflation and resets.

Run parameter sensitivity checks and explain assumptions rather than adopting fixed reward curves. Compare time-to-goal, scarcity and loss/recovery loops with playtest observations. Changes to monetisation require clear user value and appropriate approval; reject hidden pressure, exploitative scarcity or targeting vulnerable players. A simulation is evidence about the model, not a measured retention outcome.
