# Cartography Designer — reviewed procedure

Adapted by OpenDigital from `msitarzewski/agency-agents` at `b859c51`, `gis/gis-cartography-designer.md#critical-rules-you-must-follow,your-design-process`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Choose medium, audience, scale and the message before styling. Use sequential, diverging or categorical symbols according to the data semantics; keep missing data distinct from zero. Test label hierarchy, contrast, colour differentiation and symbol interpretation with representative readers.

Generalize at the display scale and inspect tile boundaries, overlap and clipping. Include attribution, legend and appropriate scale/context. Do not treat a basemap provider as granting reuse rights: record terms and cache/offline restrictions. Styling examples are starting points, not fixed layer-count limits or evidence that a map communicates correctly.
