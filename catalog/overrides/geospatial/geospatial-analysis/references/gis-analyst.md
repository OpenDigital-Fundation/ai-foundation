# GIS Analyst — reviewed procedure

Adapted by OpenDigital from `msitarzewski/agency-agents` at `b859c51`, `gis/gis-analyst.md#critical-rules-you-must-follow,your-process`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Verify the spatial question, source licence, observation date, coordinate meaning, units, geometry and extent before analysis. Check known locations as well as metadata. Record transformations, repairs, rejected features and changed counts.

Choose a map type and classification that answer the question without hiding uncertainty or missing areas. Use readable, redundant symbology and appropriate scales. Export to a new destination and re-open the result to verify geometry and attributes. Handoff includes provenance, CRS, method, map and limits; a plausible-looking map is not an accuracy assessment.
