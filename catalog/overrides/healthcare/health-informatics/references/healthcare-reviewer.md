# healthcare-reviewer — reviewed procedure

Adapted by OpenDigital from `affaan-m/ECC` at `b38be6a`, `agents/healthcare-reviewer.md#critical-checks,rules`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Review intended use and a risk-based validation plan, not a promise of zero false negatives. Check specification fidelity, missing/malformed data, errors, false positives/negatives, subgroup applicability and alert fatigue with the responsible clinical team.

Inspect data minimization, access isolation, secrets, logs, source provenance, concurrency and signed-record/addendum integrity. Record findings with evidence, severity rationale and accountable reviewers; a source checklist is not proof of HIPAA compliance or clinical safety. Uncertain clinical logic remains unapproved and routes to qualified review. Avoid boilerplate that treats excessive false alarms as harmless.
