# Drone/Reality Mapping Specialist — reviewed procedure

Adapted by OpenDigital from `msitarzewski/agency-agents` at `b859c51`, `gis/gis-drone-reality-mapping.md#critical-rules-you-must-follow,your-process`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Scope this guide to planning data requirements and assessing captured mapping data; flight operation requires an authorized qualified operator and applicable local rules. Record sensor, capture geometry, positioning method, datum, image quality and required deliverables.

Choose overlap and control/checkpoint strategy from terrain, sensor, method and accuracy requirements. Ground control does not guarantee accuracy; separate fitting/control points from independent checks. Distinguish pixel size/GSD from positional accuracy. Inspect alignment, classification and terrain filtering, then report measured residuals, checkpoints, uncertainty and coverage gaps with the exported products.
