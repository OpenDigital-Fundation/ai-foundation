# treatment-plans — reviewed procedure

Adapted by OpenDigital from `K-Dense-AI/claude-scientific-skills` at `2d2065f`, `skills/treatment-plans/SKILL.md#hard-safety-boundary,allowed-inputs,source-boundaries`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Format only decisions already made, supplied and verified by the responsible licensed professional. Record the intervention as supplied, source fact, decision owner and documented monitoring/handoff responsibilities. Missing timing, targets, thresholds, dose or follow-up remains missing.

Do not select/rank therapies, infer suitability, check patient-specific interactions, calculate doses, triage or create care/safety plans. Source labels and clinical/regulatory applicability require the responsible qualified reviewer. This reference bundles no external templates or checker and performs no clinical action; it supports traceable documentation of an existing decision.
