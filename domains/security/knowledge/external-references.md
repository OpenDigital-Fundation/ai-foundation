# External security references

Material the security skills point to but this repository does not copy, because its licence does not permit redistribution here. Read it at the source; do not paste its text into this repository.

| Resource | What it is | Licence | Use from this catalog |
|---|---|---|---|
| [SecurityStandards/agent-pentester](https://github.com/SecurityStandards/agent-pentester) (Shannon) | Autonomous pentester for web apps and APIs: reads source, finds attack vectors, runs real exploits | AGPL-3.0 | Install separately for authorised penetration tests; `security:security-audit` covers source-first review |
| [SecurityStandards/security-standards](https://github.com/SecurityStandards/security-standards) | Consolidated policies, frameworks, checklists, questionnaires and templates | none declared | Reference when writing security policies or answering questionnaires |
| [SecurityStandards/CTOSecurityChecklist](https://github.com/SecurityStandards/CTOSecurityChecklist) | SaaS CTO security checklist | CC BY-NC-SA 4.0 (non-commercial) | Read-only reference; do not reuse in commercial deliverables |
| [SecurityStandards/DevOpsSecurityChecklist](https://github.com/SecurityStandards/DevOpsSecurityChecklist) | DevOps security checklist | CC BY-NC-SA 4.0 (non-commercial) | Read-only reference; do not reuse in commercial deliverables |
| [SecurityStandards/security-policy-templates](https://github.com/SecurityStandards/security-policy-templates) | Policies and control procedures mapped to HIPAA, NIST CSF, PCI DSS, FedRAMP, CIS | see repository | Starting point for compliance programmes (`legal-compliance` domain) |
| [SecurityStandards/agent-reverse-engineer](https://github.com/SecurityStandards/agent-reverse-engineer) | Reverse engineering with agents, from app behaviour to native binaries | MIT | Separate tool/MCP server; not vendored |
| [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/), [OWASP Top 10](https://owasp.org/Top10/), [OWASP Top 10 for LLM Applications](https://genai.owasp.org/) | Verification standard and top-risk lists | CC BY-SA | Cite by requirement ID in findings |
