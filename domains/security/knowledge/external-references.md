# External security references

Material the security skills point to but this repository does not copy, because its licence does not permit redistribution here. Read it at the source; do not paste its text into this repository.

| Resource | What it is | Licence | Use from this catalog |
|---|---|---|---|
| [SecurityStandards/agent-pentester](https://github.com/SecurityStandards/agent-pentester) (Shannon) | Autonomous pentester for web apps and APIs: reads source, finds attack vectors, runs real exploits | AGPL-3.0 | Install separately for authorised penetration tests; `security:security-audit` covers source-first review |
| [SecurityStandards/security-standards](https://github.com/SecurityStandards/security-standards) | Consolidated policies, frameworks, checklists, questionnaires and templates | none declared | Reference when writing security policies or answering questionnaires |
| [SecurityStandards/CTOSecurityChecklist](https://github.com/SecurityStandards/CTOSecurityChecklist) | SaaS CTO security checklist | CC BY-NC-SA 4.0 (non-commercial) | Read-only reference; do not reuse in commercial deliverables |
| [SecurityStandards/DevOpsSecurityChecklist](https://github.com/SecurityStandards/DevOpsSecurityChecklist) | DevOps security checklist | CC BY-NC-SA 4.0 (non-commercial) | Read-only reference; do not reuse in commercial deliverables |
| [SecurityStandards/security-policy-templates](https://github.com/SecurityStandards/security-policy-templates) | Policies, standards and control procedures mapped to HIPAA, NIST CSF, PCI DSS, FedRAMP and CIS Controls | CC BY-SA 4.0 (ShareAlike) | Starting point for `legal-compliance:compliance-programs`; derivatives must keep the same licence, so it is linked, not copied |
| [SecurityStandards/vsaq](https://github.com/SecurityStandards/vsaq) | Interactive questionnaire app to assess the security programmes of third parties (vendors) | Apache-2.0 | Vendor security reviews in `legal-compliance:compliance-programs` |
| [SecurityStandards/security-page](https://github.com/SecurityStandards/security-page) | Open-source template for a public security page (disclosure policy, contact) | MIT | Publishing a vulnerability-disclosure page alongside `security.txt` |
| [SecurityStandards/open-intelligence](https://github.com/SecurityStandards/open-intelligence) | Open catalogue of OSINT sources focused on Brazil, with a JSON dataset and an investigation guide | MIT | Authorised OSINT and reconnaissance; see `security:security-audit` (reconnaissance) |
| [SecurityStandards/awesome-security](https://github.com/SecurityStandards/awesome-security) | Curated list of security standards, policies, checklists, AI agents, tools and benchmarks | none declared | Discovery of further tools and standards |
| [SecurityStandards/agent-reverse-engineer](https://github.com/SecurityStandards/agent-reverse-engineer) | Reverse engineering with agents, from app behaviour to native binaries | MIT | Separate tool/MCP server; not vendored |
| [OWASP ASVS](https://owasp.org/www-project-application-security-verification-standard/), [OWASP Top 10](https://owasp.org/Top10/), [OWASP Top 10 for LLM Applications](https://genai.owasp.org/) | Verification standard and top-risk lists | CC BY-SA | Cite by requirement ID in findings |
| [trailofbits/skills](https://github.com/trailofbits/skills) | Security-auditor skills: differential and language-specific review (C/C++, Rust), fuzzing (AFL++, cargo-fuzz, Atheris), CodeQL and Semgrep, constant-time and zeroization audits, smart-contract scanners, CVSS scoring, supply-chain risk | CC BY-SA 4.0 (ShareAlike) | Install separately for deep audits; `security:security-audit` covers the general review flow |
| [getsentry/skills `security-review`](https://github.com/getsentry/skills) | Vulnerability-review skill with per-class references | CC BY-SA 4.0 (ShareAlike) | Read at the source; the rest of that collection is Apache-2.0 |
