# A session with observable decision points

## Original synthetic example: reading a misleading chart

Audience: adults with basic chart familiarity; 30-minute session; no account or software installation. Goal: identify how an axis choice changes the apparent size of a difference, using two supplied charts and numerical labels.

| Minutes | Facilitator | Learner activity | Decision |
|---|---|---|---|
| 0–4 | Show an accessible chart and ask what comparison it supports | Individual prediction, spoken or written | Check whether axis labels are being read |
| 4–10 | Model reading the scale and relating it to the numbers | Annotate or describe the comparison | If labels remain confusing, use a simpler numeric example |
| 10–18 | Give two charts of identical values | Compare interpretations with a partner or privately | Listen for the misconception that visual height is always a ratio |
| 18–25 | Ask for a justified redesign | Draw or describe a corrected display | If the explanation omits the scale, prompt once and retry |
| 25–30 | Present a fresh chart and summarize the decision rule | Explain independently, then name a next question | Distinguish a supported explanation from a guess |

This is a proposed schedule, not an observed classroom result. With a larger group or access needs, adjust the activity and transition time instead of exceeding the session silently.

## Choose participation without changing the target

Offer readable labels, text equivalents and a keyboard-compatible response route. If the target is interpreting a chart, oral or written reasoning may show the same construct. If the target is fluent spoken explanation, substituting writing alone changes the construct; discuss the access arrangement and what will be assessed.
