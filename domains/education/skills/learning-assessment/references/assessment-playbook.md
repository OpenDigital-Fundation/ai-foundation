# An assessment that supports a bounded claim

## Original synthetic blueprint

Outcome: critique an unfamiliar chart using supplied numerical evidence and propose a justified revision.

| Evidence | Task | Scoring focus | Limitation |
|---|---|---|---|
| Interpretation | Explain the comparison in a new chart | Correct scale, units and relationship | One chart samples only one context |
| Judgement | Identify one supported and one unsupported conclusion | Link each judgement to the supplied values | A memorized slogan is insufficient |
| Revision | Annotate or describe a corrected display | Fix the identified issue without distorting data | Visual polish is not the target |

Provide text equivalents and a response format compatible with the intended construct. Give the rationale after a practice attempt; keep a live assessment answer key separate when the requester is administering it.

## Original analytic rubric excerpt

| Criterion | Meets this task's expectation | Developing | Not yet evidenced |
|---|---|---|---|
| Interpretation | Units and scale support the stated comparison | Correct relationship with one material omission | Relationship contradicts supplied data or is absent |
| Justification | Claims connect to specific numerical evidence | Relevant evidence with an unsupported inferential step | Assertion without relevant support |
| Revision | Corrects the diagnosed issue and preserves the data | Plausible correction leaves an identified ambiguity | Changes the data or does not address the issue |

These descriptors are a draft for this task, not a validated scale or authorized pass threshold. If official scoring is needed, the responsible educator chooses weights/cut scores, checks exemplars and moderates disagreements before use.

## Feedback example

“You correctly named the unit. Your ratio conclusion uses bar height even though the vertical axis starts above zero. Recheck the supplied values, revise that sentence and explain whether the conclusion still holds.” Describe the work; avoid attributing the error to laziness or a fixed learner ability.
