# Revised Bloom taxonomy as an alignment tool

The revised taxonomy distinguishes cognitive processes (Remember, Understand, Apply, Analyze, Evaluate, Create) and knowledge types (factual, conceptual, procedural, metacognitive). See [Cornell on outcome types](https://teaching.cornell.edu/teaching-resources/assessing-student-learning/learning-outcome-types-and-recommended-assessment) and the [Vanderbilt teaching overview](https://cft.vanderbilt.edu/wp-content/uploads/sites/59/BloomsTaxonomy-mary-forehand.pdf). These categories help describe the requested task; they are not learner ranks or a numeric mastery score. Do not reproduce copyrighted pyramids or verb charts.

## Original examples: evaluating information in charts

| Process | Example task | Evidence to inspect |
|---|---|---|
| Remember | Identify a supplied chart's unit | The correct unit, with permitted aids stated |
| Understand | Explain what the plotted change represents | An explanation consistent with the values |
| Apply | Use a supplied comparison rule on another chart | Correct steps and result |
| Analyze | Separate the influence of scale and changed values | A defensible decomposition |
| Evaluate | Judge two displays against explicit communication criteria | Evidence-based judgement and trade-offs |
| Create | Produce a display for a new audience and justify choices | A coherent design checked against constraints |

The same word can hide different demands: “design” by filling an almost completed template may require less independent reasoning than evaluating an unfamiliar claim. A difficult memory question is still not proof of evaluation. These examples are choices for this subject, not a universal ordered lesson sequence.

## Two-dimensional design record

For each outcome record both process and knowledge: e.g. Analyze × conceptual for separating misleading visual relationships; Apply × procedural for carrying out an agreed plotting method; Evaluate × metacognitive for checking one's own decision strategy. Include attitudes, participation or physical performance with their own observable evidence when they matter; do not force every outcome into cognitive Bloom categories.

## Original alignment example

Outcome: using an unfamiliar chart and a supplied numerical table, critique whether the visual comparison is supported and justify one revision.

Evidence: an independent annotated critique; criteria cover correct interpretation, numerical support and a justified revision. Practice: model a critique, compare a counterexample, then critique a fresh chart with feedback. A quiz that only names chart types leaves this outcome untested. If time allows only the quiz, change the scope or the assessment rather than asserting full alignment.
