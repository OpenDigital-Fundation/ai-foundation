# Level Designer — reviewed procedure

Adapted by OpenDigital from `msitarzewski/agency-agents` at `b859c51`, `game-development/level-designer.md#critical-rules-you-must-follow,your-workflow-process`. See this domain’s PROVENANCE.yaml. This is a reviewed procedure, not an installed upstream tool or a validated runtime example.

Sketch a traversal graph with entrances/exits, landmarks, encounter beats, recovery spaces and critical-path alternatives. Record expected player knowledge at each gate. Use sight lines, affordances and feedback to communicate choices without relying on a single visual or audio cue.

Block out the space at the intended movement scale, then test navigation, backtracking, failure/retry and optional routes. Observe where players become lost or misread danger. Iterate layout before expensive decoration. Deliver the flow, encounter assumptions, test observations and engine constraints to the implementation owner.
