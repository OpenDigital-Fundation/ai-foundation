# Plano — Contrato de manutenção e documentação do repositório

## Arquitetura e contratos

Preservar a organização pública por domínio determinada no AGENTS.md. O README encaminha a catálogo, facetas, profiles e contribuição. `docs/architecture/repository-layout.md` concentra o contrato operacional; `docs/reviews/repository-organization.md` registra evidências desta revisão. Governança em português; artefatos mantêm idioma original.

Geradores de docs acrescentam sumários, links de artefato e de manifesto de curadoria sem uma nova taxonomia editorial. Testes conferem links locais dos documentos tocados, completude dos índices e determinismo. O runbook usa o ambiente Python existente. O ROADMAP remove o quadro de estado duplicado; cada tasks.md continua responsável pelo andamento de sua spec.

## Verificação

Testes unitários dos contratos alterados, suíte completa do tooling, validação estática do catálogo, conferência de links e comparação da projeção com a baseline. Sem execução de scripts upstream ou avaliações pagas.
