# Documentação

| Objetivo | Documento |
|---|---|
| Encontrar capacidades | [Catálogo](CATALOG.md) ou [facetas](FACETS.md) |
| Entender e manter o repositório | [Contrato de diretórios e fluxo de manutenção](architecture/repository-layout.md) |
| Conferir a revisão estrutural | [Revisão de organização](reviews/repository-organization.md) |
| Conferir licenças e conteúdo upstream | [Fontes](SOURCES.md) e [avisos de terceiros](../THIRD_PARTY_NOTICES.md) |
| Entender requisitos e sequência de implementação | [ROADMAP de specs](specs/ROADMAP.md) |
| Entender uma decisão arquitetural | [ADRs por domínio](adr/) |

`CATALOG.md`, `FACETS.md` e `SOURCES.md` são índices gerados. Specs e ADRs são documentos editoriais: uma feature por spec, uma decisão por ADR. Evidências de uma revisão ficam em `reviews/`; dados operacionais ficam em `catalog/inventory/`.
